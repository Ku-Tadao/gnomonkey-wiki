# Update: Entry Mode CM CoX

## Stats and numbers

- An Entry Mode CM CoX raid gives about 45k points over the raid. ([2025-05-01 1:04](https://youtu.be/jdvQVwg8niM?t=64))
- Gnomonkey says completing an Entry Mode CM CoX gives roughly 45k points and a Combat Achievement. ([2025-05-01 59:56](https://youtu.be/jdvQVwg8niM?t=3596))

## Tips

- Gnomonkey says you can also do Entry Mode CM CoX in teams, where it is even easier because teammates can teach a basic version. ([2025-05-01 1:01:52](https://youtu.be/jdvQVwg8niM?t=3712))

## Opinions

- Gnomonkey says Entry Mode CM CoX is a good opportunity to learn Challenge Mode and Chambers of Xeric in general because you do not have to scout and you get to practise every possible room in a row. ([2025-05-01 0:32](https://youtu.be/jdvQVwg8niM?t=32))
- Gnomonkey says that if you have a Twisted bow, doing regular full-scale Challenge Mode is much better for points, but for players without mega rares or with only a Shadow, Entry Mode is really solid for points. ([2025-05-01 1:04](https://youtu.be/jdvQVwg8niM?t=64))
- Gnomonkey says Entry Mode gives so many brews and potions that it is a great way to learn no-prep Chambers, in place of scouting for Vanguard raids. ([2025-05-01 1:33](https://youtu.be/jdvQVwg8niM?t=93))
- Gnomonkey says the Entry Mode raid gives effectively unlimited brews, so it is great for learning no-prep, solos and Chambers in general, and he considers the update a nice learning tool that also lets you escape scouting. ([2025-05-01 1:00:50](https://youtu.be/jdvQVwg8niM?t=3650))

## Events

- Jagex released Entry Mode challenge mode Chambers of Xeric, which has every room of the raid at once as in Challenge Mode but at a normal scale rather than the hugely scaled-up Challenge Mode stats. ([2025-05-01 0:00](https://youtu.be/jdvQVwg8niM))
