**Player versus player** is a mechanic topic that Gnomonkey covers in 2 videos between 2026-05-27 and 2026-06-04. This article is a stub: his statements are grouped by type, repeated ones merged.

## Gnomonkey's opinion

* Gnomonkey says PvP is a blind spot for him and he would only ask that PvP be made more similar to the main game, giving anglerfish not overhealing in active combat as an example of an unnecessary difference.[^NzW7JFgc8qU-1892]
* Gnomonkey says he has only recently started doing any PvP so does not claim to have an angle on these changes, and asks viewers to comment.[^6tsf-brc-sE-2440]

## Events

* The blowpipe-style 'outlattle' (Eclipse atlatl) is made to attack one tick slower unless the full eclipse moon set is worn, and the Soulflame horn is nerfed in how it can be used with the ancient mace in clan spam.[^6tsf-brc-sE-2440]
