**Opinion: Community modding tools for Project Zanaris** is an opinion topic that Gnomonkey covers in 1 video on 2024-12-29. This article is a stub: his statements are grouped by type, repeated ones merged.

## Gnomonkey's opinion

* Gnomonkey believes Jagex is going about Project Zanaris the wrong way: it needs to give the community engine access or a scripting language such as Lua so players can make things, as Jagex cannot be adding parameters long term because it will not devote the dev time.[^Xfrnx3sHmzY-567]
* Gnomonkey points to RuneLite plugins such as Bronzeman mode and Prop Hunt as examples of community game modes that work really well, and says Jagex cannot be expected to code things like Bronzeman mode into private servers.[^Xfrnx3sHmzY-593]
* Gnomonkey says that if Jagex hands the community the keys, players could port Bronzeman mode server-side so items must be found and unlocked before they can be bought from other players, running a full server off it.[^Xfrnx3sHmzY-654]
* Gnomonkey compares Zanaris to Garry's Mod, which grew huge servers such as roleplay, jailbreak, prop hunt and randomizer servers from purely community-made ideas.[^Xfrnx3sHmzY-654]
* Gnomonkey suggests a randomizer server where drops of similar rarity are swapped, for example the Dragon platebody drop from Mithril dragons swapped with a Twisted bow, as a server-wide scavenger hunt lasting a week or two; he says a basic randomizer was one of the game jam projects mentioned on the modcast.[^Xfrnx3sHmzY-704]
* Gnomonkey would love to see an anarchy server like Minecraft's 2b2t where botting, cheating and manipulation are allowed, to see an economy run by bots, and hopes Jagex leaves rule enforcement to the server host.[^Xfrnx3sHmzY-764]
* Gnomonkey says high-quality community mods and bosses could be refined and added to the main game, citing Binding of Isaac, where a huge overhaul mod became DLC after the developers hired the team.[^Xfrnx3sHmzY-826]
* Gnomonkey argues private servers would let Jagex find new talent, collect bug and exploit data, and possibly bring lapsed players back for a custom game mode, as many return for Leagues for a RuneScape twist.[^Xfrnx3sHmzY-886]
* Gnomonkey lists risks of opening the engine to the community: players finding severe exploits such as dupes, invincibility or crash bugs; more bot problems; and Jagex's inability to police rule breakers, gold selling, scams or bans on private servers.[^Xfrnx3sHmzY-986]
* Gnomonkey argues that platforms built around modding such as Minecraft, Roblox, Garry's Mod and GTA V roleplay servers have huge playerbases, so Zanaris is Jagex's chance to reach far more than players from back in the day.[^Xfrnx3sHmzY-1145]
* Gnomonkey argues that private servers will be dead within six months if Jagex alone provides updates, as popular randomizers such as the Ocarina of Time one stay alive because the community updates them roughly weekly.[^Xfrnx3sHmzY-1225]
* Gnomonkey says Jagex's talk of removing the sandbox walls is not true freedom since parameters just change the walls, and concludes 'do it right or don't do it', saying community modding tools are the single most important thing.[^Xfrnx3sHmzY-1289]
* Gnomonkey says Jagex needs a clear plan for monetization and policing before building basic infrastructure, and he considers policing servers itself not feasible for Jagex.[^Xfrnx3sHmzY-1380]
