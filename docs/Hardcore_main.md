**Hardcore main** is an account topic that Gnomonkey covers in 2 videos between 2026-08-12 and 2026-08-21. This article is a stub: his statements are grouped by type, repeated ones merged.

## Methods

* Gnomonkey's hardcore main proposal is a separate server with its own economy and Grand Exchange, like WoW hardcore or Deadman, where you start fresh, item value is tied to how dangerous they are to obtain, and dying resets you to Lumbridge with zero stats, quests and diaries gone.[^FrZfpY0uoko-1413]
* In Gnomonkey's hardcore main idea, dying lets you keep only what is in your bank, which he suggests solves the mule problem by making every account a mule by default.[^FrZfpY0uoko-1467]

## Gnomonkey's opinion

* In the survey of potential game modes, the one Gnomonkey wanted most was a hardcore main, which he says cannot be recreated with plugins.[^FrZfpY0uoko-1393]
* Gnomonkey acknowledges bots, swapping and higher GP value as big problems for a hardcore main server and suggests Jagex test it temporarily for two to three months with boosted drop rates and XP to see if there is enough interest.[^FrZfpY0uoko-1500]
* Gnomonkey says hardcore main cannot be replicated with a plugin because he wants it on completely separate servers with a separate economy, and that putting it on the default world would affect the economy and not differ enough from hardcore Ironman.[^8hDdqKnk2cw-1410]
* Gnomonkey would like Jagex to try a temporary hardcore server with boosted drop and XP rates, like the Grid Master event, noting issues such as muling, bots and swapping, and says he would vote no a million times if it were packaged as an afterthought like Bronzeman was.[^8hDdqKnk2cw-1437]
