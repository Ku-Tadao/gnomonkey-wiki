# Account security

Gnomonkey covers this topic in 2 videos (2025-01-16 to 2025-01-17). Everything below is what he said, cited to the video.

## Opinions

- Gnomonkey says players have asked for character cloning after bugs or hacks for a long time and Jagex has refused, and he objects to it being offered only for money. ([2025-01-16 5:29](https://youtu.be/RkCY5EW5uoc?t=329))
- Gnomonkey says players have been asking for better account security, better account recovery options and better API access for years, and it is outrageous that Jagex is offering to sell them. ([2025-01-16 19:31](https://youtu.be/RkCY5EW5uoc?t=1171))
- Gnomonkey says getting a response within two weeks from email customer support and being able to talk to a real person should not be something sold. ([2025-01-16 20:03](https://youtu.be/RkCY5EW5uoc?t=1203))
- Gnomonkey says he wanted clear steps for preventing accounts from being hacked, better account security, and better account recovery options after a hack, and says the apology only mentions player support. ([2025-01-17 11:03](https://youtu.be/cGiq6OwLovw?t=663))
- Gnomonkey says Jagex has already raised membership prices relatively recently, charges per character slot, and had considered splitting character slots and selling them at different rates, and suggests it could instead give a free Ironman with the main account. ([2025-01-17 11:03](https://youtu.be/cGiq6OwLovw?t=663))

## Events

- The survey's additional account security features included passkeys, time-based one-time passwords for logging in, and the option of account recovery via character cloning. ([2025-01-16 5:06](https://youtu.be/RkCY5EW5uoc?t=306))
- The survey's pre-verified account recovery option would guarantee recovery of a Jagex account if compromised, for example via a system using the player's real-world ID to verify them. ([2025-01-16 6:16](https://youtu.be/RkCY5EW5uoc?t=376))
- In its blog response Jagex said robust customer support is a baseline expectation that should remain a standard part of membership, so it would not be sold. ([2025-01-16 15:38](https://youtu.be/RkCY5EW5uoc?t=938))
