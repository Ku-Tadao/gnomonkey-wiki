**Account security** is a mechanic topic that Gnomonkey covers in 2 videos between 2025-01-16 and 2025-01-17. This article is a stub: his statements are grouped by type, repeated ones merged.

## Gnomonkey's opinion

* Gnomonkey says players have asked for character cloning after bugs or hacks for a long time and Jagex has refused, and he objects to it being offered only for money.[^RkCY5EW5uoc-329]
* Gnomonkey says players have been asking for better account security, better account recovery options and better API access for years, and it is outrageous that Jagex is offering to sell them.[^RkCY5EW5uoc-1171]
* Gnomonkey says getting a response within two weeks from email customer support and being able to talk to a real person should not be something sold.[^RkCY5EW5uoc-1203]
* Gnomonkey says he wanted clear steps for preventing accounts from being hacked, better account security, and better account recovery options after a hack, and says the apology only mentions player support.[^cGiq6OwLovw-663]
* Gnomonkey says Jagex has already raised membership prices relatively recently, charges per character slot, and had considered splitting character slots and selling them at different rates, and suggests it could instead give a free Ironman with the main account.[^cGiq6OwLovw-663]

## Events

* The survey's additional account security features included passkeys, time-based one-time passwords for logging in, and the option of account recovery via character cloning.[^RkCY5EW5uoc-306]
* The survey's pre-verified account recovery option would guarantee recovery of a Jagex account if compromised, for example via a system using the player's real-world ID to verify them.[^RkCY5EW5uoc-376]
* In its blog response Jagex said robust customer support is a baseline expectation that should remain a standard part of membership, so it would not be sold.[^RkCY5EW5uoc-938]
