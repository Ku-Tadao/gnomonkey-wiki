# K'ril Tsutsaroth

Gnomonkey covers this topic in 2 videos (2022-03-19 to 2024-05-12). Everything below is what he said, cited to the video.

| | |
|---|---|
| **Type** | boss |
| **Videos** | 2 (first 2022-03-19, latest 2024-05-12) |

## Methods

- Gnomonkey completed a K'ril kill on his first try using the 5-0 method with the wiki's downgraded mage gear, estimating from Ward of Arceuus that the kill took about two and a half minutes. ([2024-05-12 4:48](https://youtu.be/_nMz6X90hb0?t=288))

## Stats and numbers

- Gnomonkey's downgraded K'ril setup has 20 melee defence, 17 range defence and 74 mage defence, which he describes as essentially no defence. ([2024-05-12 2:03](https://youtu.be/_nMz6X90hb0?t=123))
- Gnomonkey states K'ril Tsutsaroth has 200 mage level and 130 mage defence, so magic accuracy matters a lot against him. ([2024-05-12 10:23](https://youtu.be/_nMz6X90hb0?t=623))

## Tips

- The imps in the K'ril Tsutsaroth room are demons, so Demon Bane can be used on them. ([2024-05-12 2:03](https://youtu.be/_nMz6X90hb0?t=123))
- On the 5-0 method Gnomonkey notes you need full run energy, and a stamina potion helps because the bridge drains some run energy. ([2024-05-12 4:30](https://youtu.be/_nMz6X90hb0?t=270))

## Opinions

- Gnomonkey says Kril Tsutsaroth has many methods (solo 5-0 with a Twisted bow, DOLO, trolling, resupply alts) and rates him B tier, though even the 5-0 is just clicking the right tiles and then Kril, not exceptional skill. ([2022-03-19 8:11](https://youtu.be/HkVt4enEesI?t=491))
- Gnomonkey says that normally with Shadow you would kill K'ril in about three hits, and that the wiki's downgraded setup is what you would use only if going for a combat achievement. ([2024-05-12 4:38](https://youtu.be/_nMz6X90hb0?t=278))
- Gnomonkey says that against K'ril, where he has 200 mage and 130 mage defence, accuracy starts mattering a lot, so about 20% more accuracy gives a big improvement. ([2024-05-12 10:23](https://youtu.be/_nMz6X90hb0?t=623))

## Events

- Gnomonkey attempts K'ril Tsutsaroth using Demon Bane spells with the OSRS Wiki's worst recommended mage downgrades, choosing it because the wiki suggests a Skull sceptre. ([2024-05-12 0:00](https://youtu.be/_nMz6X90hb0))
- Gnomonkey's attempt to face-tank K'ril in the wiki's worst mage gear failed after he got K'ril to about half health, so he switched to the 5-0 method. ([2024-05-12 3:26](https://youtu.be/_nMz6X90hb0?t=206))
