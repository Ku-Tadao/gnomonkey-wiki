# GnomonkeyRS Wiki

An unofficial, OSRS-Wiki-style knowledge base built from the YouTube channel [GnomonkeyRS](https://www.youtube.com/@GnomonkeyRS). Every statement is *what Gnomonkey said in his videos* (auto-transcribed, then summarised), cited with a timestamp link. It is not independently verified game fact.

- **324** videos (2018-11-22 to 2026-09-14) — [browse all](videos/index.md)
- **561** topic pages — [browse by type](topics.md)

Each topic page ends with a **Revision history**: when a later video updates, contradicts or refines an earlier one, the page shows the latest position and the history lists what changed and in which video.
