## Stats and numbers

- Gnomonkey says not using the HP tracker could cost up to about three minutes across the run, and that Entity Hider saves about a minute. ([2025-07-13 28:20](https://youtu.be/UmAjGV8bBAQ?t=1700))

## Tips

- The most important RuneLite setup is tagging all monsters via NPC indicators by typing 'Jal*', which tags anything starting with Jal, and showing tiles on the monsters so you can see how they stack behind the pillar like Tetris pieces. ([2021-05-21 19:55](https://youtu.be/qnw3kGlpiuQ?t=1195))
- Gnomonkey recommends the external Fight Caves Waves plugin, set to show common monster names, to display which monsters appear next wave, and the GPU plugin to show the whole arena. ([2021-05-21 20:11](https://youtu.be/qnw3kGlpiuQ?t=1211))
- He advises against marking too many tiles, only what you need; his tile markers can be imported by copying the code from the description and right-clicking the world map and selecting import while inside the Inferno. ([2021-05-21 20:41](https://youtu.be/qnw3kGlpiuQ?t=1241))
- Gnomonkey says two RuneLite plugins are extremely important for Inferno speeds: Entity Hider and Tzhaar HP tracker (heard as Tizar HP tracker). ([2025-07-13 27:20](https://youtu.be/UmAjGV8bBAQ?t=1640))
- With RuneLite Entity Hider, Gnomonkey turns on hide dead NPCs so a dead NPC disappears instantly and cannot be clicked; he says this saves about a minute of lost time over a run because the character otherwise wastes time on corpses each wave. ([2025-07-13 27:20](https://youtu.be/UmAjGV8bBAQ?t=1640))
- Gnomonkey uses the Tzhaar HP tracker plugin (works in Fight Caves and Inferno) to change NPC tile colours: NPCs turn green when dead and red when a killing shot is travelling at them, so he can start shooting the next target immediately. ([2025-07-13 28:20](https://youtu.be/UmAjGV8bBAQ?t=1700))
- Gnomonkey recommends the attack timer metronome plugin for players new to the Twisted bow, as it shows a small timer over the head while on cooldown so the player knows when they can move. ([2025-07-13 29:22](https://youtu.be/UmAjGV8bBAQ?t=1762))
- Gnomonkey uses the TzHaar HP Tracker plugin to show health on the pillars and mobs, with the setting to hide them after death turned off because it bugs out with barrage. ([2026-07-13 7:34](https://youtu.be/7F5_YBzxtE8?t=454))
- Gnomonkey uses the Entity Hider plugin to hide dead NPCs after they are fully dead and the TzHaar Colosseum plugin option to hide the pillars if you prefer that. ([2026-07-13 7:34](https://youtu.be/7F5_YBzxtE8?t=454))
- The Fight Caves Waves plugin can show what is coming in the next wave. ([2026-07-13 7:34](https://youtu.be/7F5_YBzxtE8?t=454))
- Gnomonkey considers the NPC Indicators plugin very important, with the highlight true tile and highlight southwest true tile settings both on, which makes the melee safe spots understandable. ([2026-07-13 8:02](https://youtu.be/7F5_YBzxtE8?t=482))

## Trivia

- Gnomonkey says people used cheat clients in the past to get Entity Hider before it was allowed, because it was so important for Inferno. ([2025-07-13 29:22](https://youtu.be/UmAjGV8bBAQ?t=1762))
