**True tile** is a mechanic topic that Gnomonkey covers in 1 video on 2020-12-09. This article is a stub: his statements are grouped by type, repeated ones merged.

[TOC]

## Methods

* While running you are not moving the whole distance from the game's perspective; you effectively teleport two tiles per game tick, skipping every other tile.[^CfKUQwVJbi0-56]
* The highlight current true tile option and the tile indicators plugin show this: the blue tile is where you actually are from the server's perspective.[^CfKUQwVJbi0-56]

## Stats and numbers

* Some attacks have line of sight checks that hit you regardless of running: Xarpus's poison, Galvek's wave walls, and the arrow trap in the Hallowed Sepulchre.[^CfKUQwVJbi0-89]

## Tips

* Because of the true tile, you can run over traps in the Rogues' Den without getting hit, and the same applies in many PvM situations.[^CfKUQwVJbi0-56]
* Lightning in the Hydra fight, the Olm fight, the Gauntlet, and Verzik phase 3 can all be run through if properly timed.[^CfKUQwVJbi0-56]
* Bosses' ground splats that damage you can be run over for free, including Maiden's blood splats from her and her blood spawns, Vorkath's acid (though Gnomonkey would not recommend running in that fight), and Zalcano's red ground traps, which can be run over the corners.[^CfKUQwVJbi0-89]
* You can also run right over the skull bombs in Verzik's phase two.[^CfKUQwVJbi0-89]
* The True Tile plugin feature is extremely useful because it is always accurate to the server, so you always know where you are.[^CfKUQwVJbi0-365]
